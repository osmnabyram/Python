## About

This repository is a project archive built while learning and working with Python. It spans everything from core language exercises to practical automation scripts, organised by theme below.

---

## Contents

### Core and intermediate

- Loops, functions, lists, and dictionaries
- File read/write operations
- Error handling with `try`/`except`
- Modular and functional programming examples

### Automation and bots

- Web automation with Selenium
- An appointment-booking bot
- Form-filling, login, and data-extraction bots
- Web-scraping examples

### Data handling

- Reading data from CSV, JSON, and TXT files
- Data cleaning and reshaping examples
- Basic data-visualization logic
- Matrix and list manipulation, filtering

### Mini apps and utilities

- Calculator, timer, counter
- Password generator, text converter
- Simple record-keeping and tracking tools

### Algorithms and problems

- Search and sorting algorithms
- Recursion examples
- Basic decision-making logic

## Notes

Some files are stored as `.txt` snippets rather than runnable `.py` modules. Selenium-based scripts require the `selenium` package and a matching browser driver; the appointment bot additionally uses `pytesseract` (Tesseract OCR) and `Pillow`. Credentials and target URLs in the examples are redacted and must be filled in before use.
